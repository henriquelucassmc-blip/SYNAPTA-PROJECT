# ORIENTAÇÕES

1. Acesse o link do dataset: [https://www.kaggle.com/datasets/renatosn/sao-paulo-housing-prices]

2. Leia a descrição da página, a atribuição de autoria e os termos da licença disponibilizados na página do dataset.

3. Baixe os dados pelo botão de download, após entrar na sua conta, se necessário.

4. Se o arquivo for baixado em formato ZIP, extraia seu conteúdo.

### Importante: o endereço exato do dataset original deve ser informado aqui após sua confirmação. O nome do tema, isoladamente, não permite identificar com segurança a publicação correta no Kaggle.
